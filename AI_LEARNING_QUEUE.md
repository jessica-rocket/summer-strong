# Summer Strong — AI/Coding Learning Queue

Goal: 20 minutes per day of coding/AI learning that builds real groundwork without turning into homework jail.

Jessica's current lane: vibe-coded multiple React/TypeScript/Firebase/Vercel apps, uses AI tools heavily, wants practical AI foundations and better builder instincts.

## Week 1 Theme: AI Foundations for a Vibe Coder

### Day 1 — What AI Actually Is

**Focus:** Understand the difference between AI, machine learning, generative AI, and LLMs.

**20-minute options:**
- Read/watch: “What is an LLM?” beginner explainer
- Write 5 bullets in plain English:
  - AI = broad field
  - ML = systems learning from data
  - Generative AI = creates text/images/code/etc.
  - LLM = predicts/generates language based on patterns
  - Prompting = steering the model

**Tiny build/reflection:**
- Ask ChatGPT/Claude to explain LLMs three ways: for a kid, for a project manager, for a React developer.
- Compare which explanation actually helps.

### Day 2 — Prompting Basics: Context, Task, Constraints, Output

**Focus:** Learn the anatomy of a good prompt.

Framework:
1. Context
2. Task
3. Constraints
4. Examples
5. Desired output format

**20-minute exercise:**
Take a vague prompt and improve it.

Vague:
> Help me make my app better.

Better:
> You are reviewing a React habit tracker app. Suggest 5 UX improvements for mobile users. Prioritize low-effort changes. Return bullets grouped by Today, Progress, and Stats tabs.

**Tiny build/reflection:**
- Create 3 reusable prompt templates for your coding projects.

### Day 3 — AI for React App Planning

**Focus:** Use AI before coding: specs, data models, components, edge cases.

**20-minute exercise:**
Pick one existing app idea and ask AI for:
- MVP feature list
- component breakdown
- data model
- edge cases
- testing checklist

**Tiny build/reflection:**
- Compare AI’s plan to what you would have built first.
- Note one thing it caught that you might have missed.

### Day 4 — AI Coding Safely: Don’t Trust, Verify

**Focus:** Learn how to use AI-generated code without blindly shipping it.

Checklist:
- Read the code before accepting it
- Check imports/dependencies
- Run lint/build/tests
- Test happy path
- Test weird path
- Ask: “What could break here?”

**20-minute exercise:**
Ask AI to generate a small React component, then ask it to review its own code for bugs.

**Tiny build/reflection:**
- Write your personal “AI code review checklist.”

### Day 7 — Build a Tiny AI Workflow

**Focus:** Turn learning into a tiny practical workflow.

Options:
- Create a reusable prompt for weekly Summer Strong reflection

- Create a prompt that suggests 20-minute coding lessons

**20-minute deliverable:**
Save one reusable prompt you’ll actually use again.

## Good Weekly Rhythm

- 2 days: apply to your own apps
- 1 day: review/reflect
- 1 day: tiny build or prompt workflow
